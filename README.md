## 📜 About

All the features of a CSS/SCSS file inside [Visual Studio Code](https://code.visualstudio.com/) for [scoped-styles](https://www.npmjs.com/package/scoped-styles).

### How to install ?

- [scoped-styles Syntax Highlighting](https://marketplace.visualstudio.com/items?itemName=dmaskasky.vscode-scoped-styles-syntax)

  Launch VS Code Quick Open (⌘+P), paste the following command, and press enter.

  ```text
  ext install dmaskasky.vscode-scoped-styles-syntax
  ```

- [scoped-styles Language Server](https://marketplace.visualstudio.com/items?itemName=dmaskasky.vscode-scoped-styles-languageserver)

  Launch VS Code Quick Open (⌘+P), paste the following command, and press enter.

  ```text
  ext install dmaskasky.vscode-scoped-styles-languageserver
  ```

#### The 2 extensions are also available on [open-vsx](https://open-vsx.org/)

- [scoped-styles Syntax Highlighting](https://open-vsx.org/extension/dmaskasky/vscode-scoped-styles-syntax)
- [scoped-styles Language Server](https://open-vsx.org/extension/dmaskasky/vscode-scoped-styles-languageserver)
