# vscode-scoped-styles-syntax

[Main GitHub Repo](https://github.com/dmaskasky/vscode-scoped-styles/).

Syntax highlighting for [scoped-styles](https://github.com/vercel/scoped-styles).

<img src="https://raw.githubusercontent.com/dmaskasky/vscode-scoped-styles/master/.github/images/syntax-highlight.png" width="550"/>

Syntaxes files are inspired by [vscode-styled-components](https://github.com/styled-components/vscode-styled-components.git).
Uses the SASS grammar from the Atom [language-sass](https://github.com/atom/language-sass/).
